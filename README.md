## 🎮 About the Game

Rock Paper Scissors is a classic hand game played between two players.  
In this project, the user plays against the computer in the terminal.  
The computer randomly selects one of the three choices, making each round unpredictable and fun.

This project was created to practice Python basics and improve problem-solving skills.

---

## 📚 What I Learned

While creating this project, I learned how to:

- Use Python functions
- Work with loops and conditions
- Validate user input
- Use dictionaries for game logic
- Generate random choices with the `random` module
- Create interactive console applications
- Organize and structure code more clearly

This project also helped me better understand program flow and user interaction in Python.
